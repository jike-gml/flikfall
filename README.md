# FlickFall V1

スマホ縦画面向けの「落下文字・単語 × 入力トレーニング」PWA試作版です。

## 実装済み
- 日本語 / English 切替
- Lv.1〜5 / AUTO
- SURVIVAL / WEAKNESS / DAILY
- 文字・単語・短文の落下
- 日本語専用フリックパッド
- 入力済み文字の色分けとクリアゲージ
- 誤入力時の画面フラッシュ・揺れ・対応端末での振動
- 英語キーパッド
- HP / SCORE / COMBO / 落下速度
- 入力速度 / 正確率計測
- 苦手文字 / 苦手方向の簡易分析
- WEAKNESSモードで苦手文字を含む出題を増加
- localStorage保存
- PWA / Service Worker

## V1の制約
- 日本語フリックは主要かな中心の試作実装です。
- 濁点・半濁点・小文字は簡易入力です。実製品版ではフリック操作列として厳密計測する設計に拡張してください。
- 単語DBは少量です。実運用では数百〜数千語に拡張してください。
- 現時点の苦手学習は軽量統計ベースです。AI/APIは使っていません。

## 起動
ローカルで直接 index.html を開くこともできますが、PWA機能は HTTP(S) 配信が必要です。
GitHub Pages / Netlify / Cloudflare Pages などの静的ホスティングにそのまま配置できます。
